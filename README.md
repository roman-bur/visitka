# Визитка «Ресторан Цветов»

Страница, на которую ведёт QR-код с бумажных визиток: баннеры с акциями, звонок, MAX, Telegram-канал, каталог ВК, адреса магазинов (2ГИС).

Сайт статический: один файл `index.html` + логотип и шрифты. Ничего не собирает с посетителей, внешних скриптов и шрифтов Google нет.

## Как поменять баннер, ссылку или телефон

1. Откройте `index.html` на GitHub → значок карандаша (Edit).
2. Найдите блок `const CONFIG = {` — всё, что меняется, находится там.
3. Баннеры — список `banners`. У каждого баннера:
   - `title` — заголовок, `text` — подпись, `cta` — надпись на кнопке;
   - `link` — куда ведёт нажатие (`#contacts` — прокрутка к контактам);
   - `image` — картинка (необязательно). Загрузите файл в папку `banners/` (Add file → Upload files) и впишите `image: "banners/имя-файла.jpg"`.
4. Нажмите **Commit changes**. Через 1–2 минуты изменения появятся на сайте.

Картинки для баннеров — горизонтальные 4:3, примерно 1200×900, JPG до 300 КБ.

## Файлы

- `index.html` — страница и настройки (`CONFIG`)
- `logo.webp` — логотип
- `fonts/` — шрифты Lora и Inter (лицензия SIL Open Font License)
- `CNAME` — адрес поддомена для GitHub Pages
